**Meta Description（241字）**
有人蹲在人行道上，用几片落叶拼了个小王子，还想着再找一片红枫叶给他当玫瑰。这周我看了写作课的作业，在一段文字里圈出名词和形容词，看人家怎么把感觉递到你眼前。这作业要每天做，做上好多年，纸上的圈存不住，也没人帮我对，那就用 Claude Code 做个 app。

头一版功能一个不缺，可我一看就知道不好看，就是个后台。两天十几轮改下来，侧边栏和大标题都拿掉了，两个按钮成了两枚红印章，一笔勾销、逐一核对。到第三天我才发现，这些选择背后是同一回事，它从头一版就在起作用，只是我没给它起名字。

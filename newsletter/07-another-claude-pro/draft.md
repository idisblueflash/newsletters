# 「与 AI 同行」电子报 #7：我又多买了一个 Claude 账号
**效率高了，睡眠却不好了**

嗨，这周你在忙什么？

从我开始做 Mentoring 服务到现在，已经开了三次视频会议了。开始我还控制不好时间，后面逐渐可以准时结束了。会上我尽可能让 Mentee 多说，多表达她的想法，我尽可能地多提问，发现她的难点就马上补上。没来得及在会上说明白的，会下再发邮件补上。

控制时间其实是小事，难的是平日大量的准备工作。比如我开始读医学论文了（如何用 AI 处理医学资料）。论文里面有大量的专业词汇，我每天早上专门划出一到两个小时来精读，把自己不懂的内容拿去问 AI，然后写到笔记里。功夫没有白费，现在开视频会我能跟上 Mentee 说的主题，还能在关键的地方提供建议。

上周说过，如果你在用 AI 做真的东西，可以来找我做 Mentoring。这件事就是这样落地的：你的专业可能千差万别，但只要有材料，我就有办法上手，然后给你用 AI 优化的建议。

现在我正在招募种子用户，如果你有需要，回复这封信来申请就行。

## 本周的输出

**凌晨三点，那行红字**

我最近又买了一个 Claude Pro 账户。有两个账户用起来真的很爽，我再也不用一边盯着 Claude 的限额，一边小心翼翼地给 Claude Code 安排任务了。我现在的精力全在项目上了。

一个账户限额到了，可以直接切到另一个上面继续工作。但毕竟是 20 美元的开销，不把它充分利用，我总觉得有点亏。尤其是那个等待限额的账户，通常会在凌晨解禁。有一段时间我还会凌晨爬起来，让 Claude Code 继续干活。

后来我的睡眠都不好了。好在我最后发现了一个办法：用脚本让 Claude Code 自动接着干活。

**别再半夜爬起来点「继续」**

这是上一篇的实操篇，从头到尾记录了一个能自动接上工作的脚本是怎么设计出来的。你不仅能从文中找到具体脚本，还能学会脚本的设计思路。细心的话，你还能体会到一个好用的工具是如何迭代出来的。

## 本周的输入

**医学论文**

我前几周开发的论文转写 MD 的工具，现在起了大作用。当时做工具的时候，完全没想到它能在几周之后帮上我的大忙。现在让 Claude 根据转写出来的 MD 内容回答我的问题，观点来自第几页第几章，它写得清楚，我看着安心。

论文没有大家想的那么难，而且我认同：「论文是品质最高的文章之一」这句话。这是教授们带着一个团队设计实验、记录下来的成果呢。

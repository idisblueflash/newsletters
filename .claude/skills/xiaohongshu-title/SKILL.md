# 小红书标题 · Title Guide

标题不是正文的摘要，是**让人点开的那一下**。正文第一行才是留住人的。

## 0 · 先要两样东西，缺一样就停下来要

1. **封面图** —— 文件路径或图片本身。没有封面 → 问，并说明「没有封面也能出标题，但会少一条约束」。
2. **正文文件** —— `xiaohongshu/<folder>/draft.zh.md` 或 `note.md`。用户没说路径 → 默认最新的一条 note，并说出你读的是哪个文件。

**不要凭记忆里的正文起标题。** 数字、结果、名词都必须能在正文里找到原话。

## 1 · 先把封面裁成 3:4

小红书封面是 **3:4，1080×1440**。截图通常不是，直接用会被上下切掉。

```bash
python3 .claude/skills/xiaohongshu-title/crop_cover.py <src.png> <out.jpg> --mode page
python3 .claude/skills/xiaohongshu-title/crop_cover.py <src.png> <out.jpg> --mode window
```

三种模式：

| 模式 | 取什么 | 补什么 | 看起来像 |
|---|---|---|---|
| `page` | 画面中央那块纸面 | 纸的颜色 | 一页书 |
| `window` | 整个应用窗口（含标题栏） | 桌面背景色 | 一个 app |
| `full` | 整张图 | 桌面背景色 | 一张截图 |

**原则：宁补不裁。** 3:4 比多数截图窄，靠裁宽度去凑会切掉内容；补背景色不丢任何东西。

**出两张给作者挑，不替作者定。** 裁法本身也是一种表述：`page` 版好看但不说这是 app，`window` 版说了 app 但少了几分干净。选哪张会影响标题补什么 —— 所以先让他选。

## 2 · 读封面：它说了什么，说不了什么

封面承担**画面**，标题承担**分类**。裁完之后，写两行：

- **封面已经说过的** —— 标题里不再出现。重复一遍只是浪费 20 个字。
  **例外：类别名词。** 封面能让人看见 `app`，但搜索读不到画面，所以 `app` / `排版` / `设计`
  该占的字照占。不重复的是画面（竖排、印章、古书），不是分类。
- **封面说不了的** —— 通常是没有「东西」的形状（一张书页不说是 app，一张截图不说是作品）。这一项必须由标题补上。

**危险信号：** 封面看起来像 A，而帖子讲的是 B。这时标题必须把 B 顶出来，否则读者按 A 的预期点进来，掉粉。

## 3 · 从正文里抽三样

不新造，只挑已经有的：

1. **一个可搜索的名词** —— 读者会去搜的词（`排版`、`独立开发`、`app`、`阅读器`）。没有 → 标题注定只能靠推荐流。
2. **一个数字或时长** —— `两天`、`十几轮`、`一个`。免费的信用。
3. **一个结果** —— 改到满意、能瞅上老半天、有人用了。

## 4 · 三个候选，三种赌注

三个候选必须是**三种不同的赌法**，不是同一句话换词：

- **赌搜索** —— 可搜索名词前置，读者搜得到。
- **赌收藏** —— 结果前置，读者觉得「这个我用得上」。
- **赌评论** —— 主张里最扎人的那一半，读者想接话。

每个候选写三行：字数 / 赌什么 / 缺什么。

## 5 · 硬规则（继承 `xiaohongshu/README.md`，逐条检查）

- **≤ 20 字**，目标 10–16。标点、空格、英文都算。
- **可搜索名词必须有**，且要是读者会主动输入的字。
- **第一人称 + 结果**（`我把…改到…`）比建议式（`你应该…`）好，也自动满足「Experience, not instruction」。
- **留一个缺口** —— 缺的是「怎么」或「发生了什么」，**不能**缺「这是什么」。
- **不重复封面说过的话。**
- **不用教程体 / 广告体**：`如何`、`N 个技巧`、`必看`、`干货`、`保姆级`。
- **不用教学语气**，不写「你应该」「规则是」。
- **不写书面化包装**：`从…出发`、`是件…的事`、`对…有着…的喜欢`。
- **表情符号不承担语义**。装饰可以，传递信息不行。
- **过口语关。** 见 README 的 spoken test：对仗、零虚词、主语漂移、一句里两次压缩 —— 中一条
  就是在写摘要，不是在说话。改法是方向（主语、虚词、结尾落在实词上），不是替他换词。

## 6 · 陌生人的测试

每条候选念一遍，回答两个问题：

- 这个人是谁？读的人知道这是写给谁的吗？
- 点进去能得到什么？

两个都答不出来 → 换掉，不要凑数。

## 7 · 输出

```
封面：<裁好的文件>
封面说了：…
封面说不了：…
可搜索名词：… / 数字：… / 结果：…

1. <标题>（N 字）— 赌 X：…  缺：…
2. <标题>（N 字）— 赌 X：…  缺：…
3. <标题>（N 字）— 赌 X：…  缺：…

我选 1，因为 …
```

最后一句说清推荐哪个、为什么，只推一个。

## 约束

- **不写进正文文件。** 作者选完、确认之后，才替换 `draft.zh.md` 顶部的 `# 题目：待定`。
- **不发明正文里没有的事实。** 数字、时长、结果、名词，正文里没有就写「缺」。
- **不美化作者的原话。** 引用正文用原话。
- 一次给三个，不给五个。候选之间要真的不同，不要同义换词。

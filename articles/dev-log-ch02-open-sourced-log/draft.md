# Vibe Coding 过程日志
为什么Vibe Coding新人应该「公开写日志」

上一集我们说到了 Vibe Coding 新人应该开始「公开写日志」。每天的总结日志就能带来这么多好处。你可能不知道，如果你在 Vibe Coding 的同时「写过程日志」会带来更大的好处：知识外化。

## 空中抛球

现在流行的 Obsidian App 把「知识外化」这个概念具象化了。不管你怎么理解它，但是你肯定认同它是把脑子里的东西记录成 Obsidian 里的一条条笔记。这是知识外化在**认知层**的体现。就是在你写下^[你也可以说出你的想法，让语音输入app转成文字]笔记的时候就对你的认知起到了作用。

根据 Miller's Law（1956），人脑的工作记忆一次只能保留**7±2**个概念，而 Cowan（2001）的修订版本更接近**4个**概念。这种生下来就有，甚至努力也不会有太明显改观的限制很多人并不知道。

这有点像是在玩「空中抛球」。你不仅要接住别人抛给你的新球，还不能让老球落地。这二个动作同时在消耗你的注意力，一直接新球的话，你的脑子很快就转不动了。「写过程日志」是把老球放到盒子里，空出来的手可以接更多的新球。

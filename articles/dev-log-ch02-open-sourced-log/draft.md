# 开始写想法流水账
为什么Vibe Coding新人应该「公开写日志」

Vibe Coding 的时候，一晃一天就过去了，你也不知道做了啥。你知道要做记录，但是你很烦这件事。你索性就让 AI 来观察你，帮你记录。

你把十几部 YouTube 丢给 AI 总结，再生成思维导图，结果竟然不靠谱。你盯着那张花花绿绿的导图，看不懂。读完总结，感觉像是那么回事。合上电脑，你还是说不上来新学的逻辑该怎么用。

奇怪了，你明明是社区老人。大半年下来攒了几百小时，每个月还烧掉大几百美金，到底在干啥？尤其是看到新人一个晚上就做出来的成果。

说白了，你是把**思考**「外包」出去了。

想高效思考，有个笨办法，把每条想法都写下来。这就是「想法流水账」。规矩很简单：一行一条，问题在前答案在后，按时间一条条往下排。
## 怎么写想法流水账

想法流水账写在哪都行，便签、备忘录、博客都可以。Vibe Coding 的话，用 Obsidian 最方便。

**第一步（只写问题）**：

```
# May 12 Thu

## 在 Claude Code 执行的时候，让一旁的 App 联动有哪些办法？
```

**第二步（问题 + 简短答案 + 候选展开）**：

```
# May 12 Thu

## 在 Claude Code 执行的时候，让一旁的 App 联动有哪些办法？共享状态文件 + 监听
- 共享状态文件 + 监听
  Skill 在每个阶段写入数据到 state.json，Web App 监听并更新展示
- Claude Code Hooks
  流程复杂，演示翻车时难恢复
- MCP工具
  需要 Web App 设计、暴露 MCP。复杂
```

**第三步（继续写第二个问题）**：

```
# May 12 Thu

## 在 Claude Code 执行的时候，让一旁的 App 联动有哪些办法？共享状态文件 + 监听

...

## 我应该复制一份 Skill 专门用于展示嘛？应该
- 直接改 Skill，会污染原版
- 复制 Skill，原版干净
- 结合 Hooks，链路长，同理上一个问题的第二个选项
```

你可能会想，这不就是子弹笔记、卡片笔记吗？还真不是。子弹笔记（Bullet Journal）管的是你今天要做的事，重点是任务清单。卡片笔记（Zettelkasten）管的是已经想清楚的知识，一张卡片一个概念，还要互相链接。费曼学习法是你学完之后，用大白话讲给别人听，验证自己懂没懂。流水账不一样，管的是你**正在想**的问题，没整理、没结论，按时间一条条排下去。

## 为什么要写下来
你的脑子能同时装下几个想法呢？

1956 年 Miller 说大概是 7 个上下的 Chunk。

2001 年 Cowan 修订成了 4 个。

Baddelay 和 Hitch 还发现了一件更糟糕的事：哪怕上面那 4 个，你也要不停地在脑子里默念，才不会忘记。问题是，默念这件事本身就在烧注意力。

就像你在玩「空中抛球」。你不仅要接住别人抛来的新球，还不能让旧球落地。这两个动作同时在消耗注意力。把想法写下来，就等于把旧球放下，腾出手接更多新球。

## 写下来可以学得更快
让 AI 帮你查资料、跑任务、头脑风暴，省下来的时间能让你学得更快。但还有一个“答案贴脸”的好处。设想第二天，你再回顾流水账，会看到这样的内容：

> ```
> # May 12 Thu
> ## 在 Claude Code 执行的时候，让一旁的 App 联动有哪些办法？ → 共享状态文件 + 监听
> ## 我应该复制一份 Skill 专门用于展示吗？ → 应该
> ## ...
> ```

问题和答案，脸贴脸地排在一起。只要扫一眼，当时的疑问和决定全看懂了。还想看看为什么这么决定？把标题点开，候选方案的细节，甚至自己的思考过程都在。Obsidian、VS Code 都支持 Markdown 文件的折叠。

要是没记下这些流水，你还要重开 Claude Code，找到当时的上下文，贴上去，再重新讨论一遍。更麻烦的是结果可能还不一样！时间多花了半个小时不说。

## 不能让 AI 帮你写 
记住不要让 AI 帮你总结。你可能会想，既然是要留下记录󠄃，那么为什么不让 AI 来写呢？还不会打断我和 Claude 的心流。

用自己的话写出来是一种主动产出。这会刺激你的大脑神经元，提升 20 - 24% 的记忆效果。而让 AI 写完，你再读，属于被动输入。你下次再打开这份流水，读的是 AI 的版本，不是你当时的思路。你得先把它翻译回自己的话，才能接着往下想。

这个提升相当于你的分数从 75 分提高到了 90 - 105分。放在高考的时候，这个差距足以跨过很多大学的录取线。

你可能还会在心里嘀咕：这么断断续续的边写边做，我的心流不就断了吗 ？ 你有没有想过，你可能在跑一个假的心流。你一个晚上和 AI一起砍瓜切菜 ，所有问题都被 AI解决了。但是第二天你回想起来，好像自己没学到什么东西。

这就像你坐上滴滴，去一家陌生城市的素餐馆。你不是司机，到了目的地，你不记得是怎么来的。换成是你自己拿着地图，踩着单车，在上海的小街靜巷边逛边骑。那么你不光记得自己是怎么来的，你还会记住这一路上的矮树阴凉、潮铺小店和在路边买到的蜜雪冰糖柠檬水。

## 做不完的也要写下来
前面说过，你正在学习的概念会消耗注意力，其实「还没做完的事情」也一样 ，甚至会不停的消耗。多数人是在业余时间 Vibe Coding 的。他们在清晨挤出满满的两个小时，尽情地 Vibe。快结束之前，一定有很多想法没有实现，这些想法可不会在你合上 MacBook 的时候一同消失。这些也要记下来。

Masicampo 和 Banmeister 在 2001 年做过一个实验：没有完成的事情会一直站着脑子的工作内存。就像那些你打开却没有关上的浏览器页面。但只要你把它们写下来，这种消耗就停止了。

不写下来的话，它们会在你吃饭的时候跳出来，通勤的时候跳出来，甚至在入睡前还会跳出来。它们会跳上一整天，没完没了。

```

从今晚开始写你自己的「想法流水账」吧。

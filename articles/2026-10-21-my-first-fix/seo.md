The First Fix: What My Taste Is Good For with a Code Agent

**URL Slug**

**Meta Description（495字）**
I used to arrive with the fix already in mind. I was the architect; the code agent was the builder.

One sentence on a concept card bothered me, and my fix was quick. The agent agreed with the problem and rejected the fix. Then I asked one more question, and the fix we landed on was simpler than either of our first ideas.

In a week of sessions I found ten moments like this. My taste was right about the problem every time.

If the agent often has the better fix, what is my taste good for?

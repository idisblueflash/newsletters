# 记一笔时间花了 0.32 美元，修好后又花了 0.31 美元

我每天半小时记一笔时间，格式是固定的：

```
7.30 遛狗，8.-10.30 背单词，10.30-11.30 做饭
```

"8." 是 8:00，"8.-10.30" 是 8:00 到 10:30。

这么死板的格式，我一直让 Claude Code 来解析。高射炮打蚊子，换成 Haiku 也是浪费 Token。

## 换成 Jev

Jev 是 TypeSafe 家的小模型，专门做选择题，又快又便宜。

我把它接进了自己做的桌面助理 Sumomo：我输入一句话，Sumomo 先问 Jev 该走哪个工作流，再交给那个工作流去跑。Jev 把握不到八成的，交给 Claude Code 兜底。

迁过来以后，记一笔时间几乎不花 Token。

## 第一次翻车

我输入 `8. refactor timelog with Jev`，意思是 8 点开始重构时间账。

Jev 判它 66% 是「别的事」，只有 34% 是记时间。没过线，转给 Claude Code 兜底。账倒是记上了，可用掉 197K Token，0.32 美元。

问题出在「refactor timelog」读起来像是要改时间账，不像是记一笔。

## 解法：先跑代码，再问模型

Claude Code 翻了我四千多条记录，发现每一条都以数字开头。它还翻出我几个月前写的时间解析代码，我自己早忘了。

于是顺序改成：

1. 先拿代码解析一遍，解析成功的，一定是时间账
2. 解析失败的，再交给 Jev 判断

连 Jev 那点 Token 也省了，断网也能记。

Claude Code 还用几个例子验证了一遍。我心想，这下能放心把活儿交给它了。

## 第二次翻车

半小时后，我输入：

```
8.30 draft post about migrating to Jev for time log script.
```

又进了兜底分支。

这回路由认对了，坏在下一步：账本路径写的是 `${HOME}/...`，没被展开成我的用户目录，脚本就去找一个叫 `${HOME}` 的文件夹。写不进去，报错，又转给 Claude Code。又是 0.31 美元。

Claude Code 先道歉，再修漏洞，最后保证：下次一定成功！

我可不敢信了。好用的工作流，是在天天用的过程中慢慢磨出来的。

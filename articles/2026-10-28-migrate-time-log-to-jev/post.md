# 换成 Jev 以后，记一笔时间反倒花了 0.32 美元

每天我都会记录自己做了什么，半小时一次。这是跟柳比歇夫学的，我管这叫「时间账」。

格式很固定：

```
7.30 遛狗，8.-10.30 背单词，10.30-11.30 做饭
```

"8." 是 8:00，"8.-10.30" 是从 8:00 到 10:30。

这种格式，我一直让 Claude Code 来提取，真是高射炮打蚊子。就算换到它家的 Haiku 小模型，也是浪费 Token。

最近 Jev 出来了。它是 TypeSafe 家的小模型，专门做选择题，又快又便宜。我终于可以把时间账迁出 Claude Code，接进我早就在用的 Sumomo 了。

Sumomo 是我自己做的生活助理，一个浮在电脑桌面上的小人儿。我输入一句话，她先问 Jev 该走哪个工作流，再交给那个工作流处理。Sumomo 负责接话，Jev 负责拿主意。Jev 拿不准的（把握不到八成），交给 Claude Code 兜底，我管这叫应急工作流。

迁过来的时间账，从头到尾不调用 Claude Code，几乎不花 Token。

在 Jev 的帮助下，Sumomo 拎得很清。

直到我输入：

```
8. refactor timelog with Jev
```

意思是 8 点开始重构时间账，这是一笔该记的时间。Sumomo 却没走时间账，而是启动了应急工作流。活儿最后是干完了，但 Token 用掉 197K，花了 0.32 美元。

这可一点也不 Nice。

我让 Claude Code 去排查。原来「refactor timelog」读起来更像是要改时间账，而不是记一笔：Jev 判它 66% 是「别的事」，只有 34% 是记时间。没过八成的线，就交给了 Claude Code 兜底。

Claude Code 翻了我四千多条记录，发现所有记录都以数字开头。它还发现，几个月前我早把时间解析写进了代码里（我自己都忘了）。

于是顺序改成：

1. 先拿代码解析一遍，解析成功的，一定是时间账
2. 解析失败的，再交给 Jev 判断

这回比接 Jev 还简单。断网也能记，Jev 那一点点 Token 也省下了。真是可喜可贺！

Claude Code 还用几个例子做了验证。看来，以后我能放心地把更多活儿交给 AI 了。

# 「我才不会半夜起来伺候 AI」，三天后凌晨三点我在敲 continue

Meetup 上有人说她经常半夜爬起来看 Claude 卡没卡住。我当时想：这也太夸张了。

三天后，凌晨三点，我起夜回来，经过书桌，想起有个任务卡在限额上。我滑了一下触控板，屏幕亮起来，一句红字：

> *You've hit your session limit · resets 2:20pm (Asia/Shanghai)*

敲了个 continue，按回车，爬回床上。

这样的晚上不止一次。有时候半夜我还得进入工作状态，帮 Claude 拍板，让它多跑一段。一周下来我的脑袋是懵的。

直到又一个晚上，我坐在没开灯的书桌前等着红字消失，突然我想起自己说过的那句话：

「我才不会半夜起来伺候 AI。」

## 问题在哪

Claude Pro 五小时额度是从我发的第一条消息起算的，不是固定钟点。2:20pm、1:20pm、11:20pm，每次不一样，我也记不住，只能守着。

不守着，就觉得那 20 美金白花了。

## 解法

写个脚本，隔几分钟去敲一次门。没解禁就回来等，解禁了自动开始干活，干完自己停，留日志。

这功能 Claude Code 本身没有，GitHub 上有人提过好几次，到现在还晾着。

那晚九点多，我离开电脑。第二天醒来，日志最后一行：`ALL_TASKS_DONE`。

我睡我的，它忙它的。
